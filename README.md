# 🚆 RailGaadi – Smart Train Tracking Platform

**RailGaadi** is a modern railway tracking platform designed to help passengers explore train routes, check train running status, and follow their journeys through an intuitive and user-friendly interface.

## ✨ Features

- 🚉 **Live Train Tracking** – Search trains by train number or name.
- 🗺️ **Interactive Journey Map** – Visualize train routes and station locations.
- 📍 **Current & Next Station** – View train station information.
- ⏱️ **Running Status** – Display train delays and running status when supported by the data source.
- 🕒 **Estimated Arrival Time** – View estimated arrival times for upcoming stations when data is available.
- 📊 **Journey Progress** – Track distance covered and remaining.
- 🔄 **Auto Refresh** – Keep train status information up to date.
- 🔗 **Share Journey** – Share a train journey link with others.
- 📱 **Responsive Design** – Designed for desktop and mobile devices.

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI:** React
- **Package Manager:** npm

## 🚀 Getting Started

### Prerequisites

Install the following tools before running the project:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Rizvanali-coder/RailGaadi.git
```

**2. Open the project folder**

```bash
cd RailGaadi
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

Visit:

[http://localhost:3000](http://localhost:3000)

## ⚙️ Configuration

If the project requires external APIs, add the required environment variables to a `.env.local` file in the project root.
